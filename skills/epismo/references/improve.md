# Improve

Use this guide when real work on a case reveals a repeatable playbook improvement.

## Separate evidence from proposal

Read the relevant case history, including handoffs when they contain evidence
for the proposed change.

- Put what happened in the case as a record.
- Put what should change next time in a suggestion.
- Keep one-off exceptions out of reusable guidance unless they reveal a general rule.

Explain the problem, proposed change, and expected benefit against the version
that produced the observation. Target a step only when the change is specific
to that step.

## Work with ownership

Before applying, compare the proposal with the current version. Publish the
change before marking the suggestion applied, so the resolution points to a
real result. Several compatible suggestions can be folded into one reviewed
version; resolve each against that result. See [Author](./author.md) for the
draft workflow.
