# Coordinate

Use this guide to decide when an ongoing effort needs separate ownership,
approval, or a durable handoff.

## Resume before starting

When a similar case exists, compare its audience and lifecycle with the new
work before reusing it. Start from a playbook version when that guidance needs
to be part of the record; use an ad hoc case when none fits.

## Make responsibility explicit only when it helps

Use the case assignee for whole-matter responsibility. Create a work task for
a concrete delegated result, and an approval task when a named person or agent
must judge a specific record. Do not create tasks just because a playbook has
steps or because work happens in parallel.

An approval task names the reviewer whose judgment is needed. Do not treat a
collaborator's ability to edit case work as that reviewer's approval.

## Close with the evidence

When closing a case or task, include final records in that transition instead
of racing a separate append. Reopening a case does not reopen its tasks.

## Treat lifecycle and access changes as consequential

Before making a case public, consider future records as well as its current
contents; later records become public without a separate access change.
