# Capture Learning

Use this guide to turn a session, completed work, or verified knowledge into durable Epismo state.

## Choose the Artifact

Capture a **workflow pack** when the value is a procedure:

- ordered actions;
- a reusable checklist;
- dependencies between steps;
- a repeatable path to an outcome.

Capture a **context pack** when the value is knowledge:

- current state and important history;
- decisions and reasoning;
- constraints and assumptions;
- findings and source references;
- unresolved questions;
- handoff information.

Use tracks instead when the material is work that should now be executed or managed.

Do not duplicate the same material across all three. Link related artifacts when needed.

## Find a Home

Search existing packs before creating one.

- Extend an existing pack when the subject, audience, and lifecycle match.
- Create a new pack when one of those boundaries is meaningfully different.
- Prefer one maintained context pack per durable topic.
- Prefer improving a fitting workflow over creating a near-duplicate.

Scan compact results first and fetch only the relevant steps or blocks.

## Capture a Workflow

Base a workflow on a proven or clearly specified procedure, not a vague aspiration.

Write:

- a title that names the outcome;
- a short description of when to use it;
- steps with one reviewable result each;
- dependencies only where order matters;
- an assignee role only when responsibility is inherent to the step;
- no organization-specific secret or transient execution detail.

Keep background knowledge in a context pack rather than embedding a large reference manual in workflow steps.

## Capture Context

Synthesize rather than copying a raw conversation. A useful context or handoff normally covers:

1. objective and scope;
2. current state;
3. decisions made and why;
4. verified evidence or artifacts;
5. constraints and risks;
6. unresolved questions;
7. concrete next actions.

Mark uncertainty. Distinguish facts from assumptions. Reference large source artifacts instead of copying them in full.

Do not save temporary status already represented by tracks, reusable steps that belong in a workflow, secrets, credentials, or unsupported guesses presented as facts.

## Verify the Capture

After writing:

- confirm the artifact type and title;
- confirm the expected steps or blocks exist;
- confirm links and references point to the intended records;
- confirm access did not change unintentionally;
- return the stable reference available from the current surface.

Create privately unless the user explicitly requests a wider audience. Apply [Share and Publish](./share.md) before changing access.
